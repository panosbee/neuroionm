Σύνδεση

Σύνδεση στην πλατφόρμα

Ο χρήστης ανοίγει τη σελίδα login, συμπληρώνει username και password και μεταφέρεται στο κεντρικό dashboard. Αν δεν υπάρχει ενεργό session, όλες οι βασικές σελίδες επιστρέφουν αυτόματα στο login.

  1. Άνοιξε τη σελίδα login.
  2. Συμπλήρωσε username και password.
  3. Πάτησε Login.
  4. Μετά τη σύνδεση χρησιμοποίησε το επάνω navigation για Home, Live, Cases, Academy, Manual ή Admin.
Ρόλοι

Admin vs User

Ο Admin διαχειρίζεται χρήστες, passwords, Knowledge Base uploads και body-map curation. Ο User χρησιμοποιεί την κλινική και εκπαιδευτική ροή χωρίς πρόσβαση στη σελίδα Admin.

  • Admin: δημιουργία χρήστη, reset password, PDF upload, Knowledge Documents, Body Map Curation.
  • User: Home, Live, Academy, Cases, Reports, Manual και AI εργαλεία.
  • Αν απλός user προσπαθήσει να ανοίξει Admin, επιστρέφει στο dashboard.

Τα τέσσερα access levels

  • Learner, Clinician και Educator εργάζονται στις κλινικές/εκπαιδευτικές σελίδες (Live, Cases, Academy, Manual, AI).
  • Μόνο ο Admin ανοίγει τη σελίδα Admin και διαχειρίζεται χρήστες, κωδικούς και Knowledge Base.
  • Οι Clinician / Educator / Admin μπορούν να γίνουν ειδικοί στο Tele· ο Learner όχι.
  • Αναλυτικά για κάθε επίπεδο και πώς ανατίθεται, δες την ενότητα Χρήστες.
Χρήστες

Δημιουργία χρήστη και ρόλοι

Η δημιουργία χρήστη γίνεται από τη σελίδα Admin (μόνο ρόλος Admin). Κάθε χρήστης έχει υποχρεωτικά και προαιρετικά στοιχεία, ένα access level (ρόλο) και μια κατάσταση (status).

Υποχρεωτικά & προαιρετικά πεδία

Συμπλήρωσε όλα τα υποχρεωτικά πεδία· τα προαιρετικά εμπλουτίζουν το προφίλ και τις αναφορές.

  • Username — 3–80 χαρακτήρες, μοναδικό.
  • Password — τουλάχιστον 8 χαρακτήρες (κουμπί «Δημιουργία» για ισχυρό τυχαίο).
  • First name και Last name.
  • Email — έγκυρη και μοναδική διεύθυνση.
  • Phone — τηλέφωνο επικοινωνίας.
  • Professional title, Specialty.
  • Organization, Department.
  • City, Country.
  • License number.
  • Notes (ελεύθερες σημειώσεις).

Access level (ρόλος) & status

  • Learner: εκπαιδευόμενος — Academy, Cases, Manual, AI· δεν ανοίγει Admin, δεν εμφανίζεται ως ειδικός Tele.
  • Clinician: κλινικός — πλήρης κλινική ροή· μπορεί να γίνει ειδικός στο Tele.
  • Educator: εκπαιδευτής — κλινική + εκπαιδευτική ροή· μπορεί να γίνει ειδικός στο Tele.
  • Admin: διαχειριστής — όλα τα παραπάνω + σελίδα Admin (χρήστες, reset password, Knowledge Base, body-map curation).
  • Active: ο χρήστης μπορεί να συνδεθεί κανονικά.
  • Pending: ο λογαριασμός υπάρχει αλλά δεν επιτρέπεται σύνδεση ακόμη — άλλαξέ τον σε Active όταν είναι έτοιμος.
  • Inactive: η σύνδεση είναι απενεργοποιημένη (π.χ. αποχώρηση)· μπορεί να επανενεργοποιηθεί.

Κανόνες & επικύρωση

  • Το email και το username είναι μοναδικά· αν υπάρχουν ήδη, η δημιουργία απορρίπτεται με σαφές μήνυμα.
  • Ο κωδικός πρέπει να έχει ≥ 8 χαρακτήρες· το κουμπί «Δημιουργία» φτιάχνει ισχυρό τυχαίο κωδικό 14 χαρακτήρων.
  • Δώσε τα αρχικά διαπιστευτήρια στον χρήστη με ασφάλεια· μπορεί να τα αλλάξει μόνος του από «Ο λογαριασμός μου».
  • Μόνο λογαριασμός με access level Admin βλέπει τη σελίδα Admin και δημιουργεί χρήστες.

Βήμα-βήμα δημιουργία

  1. Συνδέσου ως Admin και άνοιξε τη σελίδα Admin.
  2. Πήγαινε στην ενότητα Create user.
  3. Συμπλήρωσε τα υποχρεωτικά: username, password, first/last name, email, phone.
  4. Προαιρετικά πάτησε Δημιουργία δίπλα στο password για ισχυρό τυχαίο κωδικό.
  5. Πρόσθεσε προαιρετικά στοιχεία (title, specialty, organization, department, city, country, license, notes).
  6. Διάλεξε access level: Learner, Clinician, Educator ή Admin.
  7. Διάλεξε status: Active (για άμεση σύνδεση), Pending ή Inactive.
  8. Πάτησε Create user· ο χρήστης εμφανίζεται στη λίστα.
  9. Δώσε στον χρήστη το username και τον αρχικό κωδικό με ασφάλεια.
Διαπιστευτήρια

Διαπιστευτήρια & ανάκτηση κωδικού

Υπάρχουν τρεις τρόποι διαχείρισης κωδικών και ονομάτων χρήστη, ανάλογα με τον ρόλο: (1) κάθε συνδεδεμένος αλλάζει μόνος του τα δικά του από «Ο λογαριασμός μου», (2) ο Admin κάνει reset τον κωδικό ενός χρήστη, (3) ο Owner ορίζει νέα διαπιστευτήρια για τον διαχειριστή μιας εταιρείας από το control plane.

Ο λογαριασμός μου — αλλάζεις τα δικά σου διαπιστευτήρια

Στην κορυφή της σελίδας Admin υπάρχει η κάρτα «Ο λογαριασμός μου». Όποιος έχει πρόσβαση στη σελίδα Admin — ο Owner και κάθε διαχειριστής εταιρείας — αλλάζει εκεί μόνος του τον κωδικό και το όνομα χρήστη του, χωρίς να χρειάζεται κανέναν άλλον. Οι αλλαγές ισχύουν άμεσα, χωρίς επανεκκίνηση, και χρειάζονται πάντα τον τρέχοντα κωδικό για επιβεβαίωση.

  1. Άνοιξε τη σελίδα Admin· η κάρτα «Ο λογαριασμός μου» είναι στην κορυφή.
  2. Για κωδικό: συμπλήρωσε Τρέχων κωδικός και Νέος κωδικός (≥ 8 χαρακτήρες, διαφορετικός από τον τρέχοντα). Προαιρετικά πάτησε «Δημιουργία» για τυχαίο ισχυρό κωδικό.
  3. Πάτησε Ενημέρωση κωδικού· ισχύει στην επόμενη σύνδεση.
  4. Για όνομα χρήστη: συμπλήρωσε Τρέχων κωδικός και Νέο όνομα χρήστη (3–80 χαρακτήρες) και πάτησε Ενημέρωση ονόματος.
  5. Το νέο όνομα χρήστη ισχύει άμεσα· για διαχειριστές εταιρείας ανανεώνεται αυτόματα η ενεργή συνεδρία.

Reset κωδικού χρήστη (από Admin)

Όταν ένας χρήστης (learner, clinician ή educator) ξεχάσει τον κωδικό του, ο Admin τον επαναφέρει από τη λίστα Users. Δημιουργείται νέος ισχυρός κωδικός που εμφανίζεται στην οθόνη ώστε να δοθεί στον χρήστη· το reset επαναφέρει και τη δυνατότητα σύνδεσης.

  1. Άνοιξε τη σελίδα Admin και βρες τον χρήστη στη λίστα Users.
  2. Πάτησε Reset password στη γραμμή του χρήστη.
  3. Επιβεβαίωσε στο παράθυρο επιβεβαίωσης.
  4. Το σύστημα παράγει νέο κωδικό 14 χαρακτήρων και τον εμφανίζει στην οθόνη.
  5. Δώσε τον νέο κωδικό στον χρήστη με ασφάλεια· μπορεί μετά να τον αλλάξει μόνος του.

Owner — αλλαγή διαπιστευτηρίων διαχειριστή εταιρείας

Από το control plane (/owner.html, μόνο στο κεντρικό instance) ο Owner μπορεί να ορίσει νέα διαπιστευτήρια για τον διαχειριστή οποιασδήποτε εταιρείας — χρήσιμο όταν ο διαχειριστής έχασε τον κωδικό και δεν μπορεί να τον αλλάξει μόνος του. Η αλλαγή ακυρώνει αυτόματα οποιαδήποτε προηγούμενη self-service αλλαγή του διαχειριστή.

  1. Συνδέσου ως Owner και άνοιξε το /owner.html.
  2. Βρες την εταιρεία στη λίστα και πάτησε Νέα διαπιστευτήρια.
  3. Δώσε νέο κωδικό (≥ 8 χαρακτήρες) και προαιρετικά νέο όνομα χρήστη.
  4. Υπόβαλε το αίτημα· εφαρμόζεται από το σύστημα και τα νέα διαπιστευτήρια ισχύουν.
  5. Δώσε τα νέα διαπιστευτήρια στον διαχειριστή της εταιρείας.

Αν χαθεί ο κωδικός — τι κάνει ποιος

  • Χρήστης (learner/clinician/educator): ο Admin της εταιρείας κάνει Reset password από τη λίστα Users.
  • Διαχειριστής εταιρείας (Admin): αν θυμάται τον κωδικό, τον αλλάζει από «Ο λογαριασμός μου»· αν δεν τον θυμάται, ο Owner ορίζει νέα διαπιστευτήρια από το /owner.html.
  • Owner: αλλάζει τον δικό του κωδικό από «Ο λογαριασμός μου» όσο είναι συνδεδεμένος. Αν χαθεί εντελώς η πρόσβαση, η ανάκτηση γίνεται μόνο από τον διαχειριστή του server (break-glass: ρυθμίσεις περιβάλλοντος + επανεκκίνηση υπηρεσίας).

Ασφάλεια: για κάθε αλλαγή ζητείται ο τρέχων κωδικός. Ο ρόλος ενός λογαριασμού δεν αλλάζει ποτέ μέσω self-service — μια αλλαγή κωδικού ή ονόματος δεν μπορεί να ανεβάσει δικαιώματα. Τα αρχικά διαπιστευτήρια του Owner και των διαχειριστών εταιρείας προέρχονται από ασφαλείς ρυθμίσεις περιβάλλοντος στον server.

Knowledge Base

Τι είναι και τι ανεβάζουμε

Η Knowledge Base είναι η επίσημη βιβλιοθήκη εγγράφων που χρησιμοποιεί η πλατφόρμα για evidence-aware αναζήτηση και AI απαντήσεις. Όταν ανέβει PDF, το σύστημα εξάγει κείμενο, κάνει OCR όπου χρειάζεται, το χωρίζει σε τμήματα και το κάνει διαθέσιμο για retrieval.

  • Ανεβάζουμε επίσημα IONM protocols, SOPs, training manuals, procedure guidance, published references και εγκεκριμένες οδηγίες.
  • Αποφεύγουμε πρόχειρα drafts, διπλότυπα, μη εγκεκριμένο υλικό και έγγραφα με προσωπικά στοιχεία ασθενών.
  • Χρησιμοποιούμε καθαρό Title, Domain όπως spine/cranial/thyroid/ssep/pedicle/general και tags χωρισμένα με κόμμα.
  • Μετά το upload ελέγχουμε ότι το PDF εμφανίζεται στο Knowledge Documents.
  1. Άνοιξε Admin.
  2. Στο AI Knowledge Base συμπλήρωσε Title, Domain και Tags.
  3. Διάλεξε PDF.
  4. Πάτησε Upload and index.
  5. Έλεγξε τη λίστα Knowledge Documents.
Live

Κλινικός σταθμός εργασίας

Το Live είναι το βασικό κλινικό workspace. Χωρίζεται σε τρεις στήλες: αριστερά το Decision Tree, στο κέντρο το Clinical Context του επιλεγμένου node, και δεξιά τα εργαλεία.

Διάταξη οθόνης

  • Decision Tree (αριστερά): διάλεξε διαδρομή (procedure → anatomy → protocol) μέχρι το σχετικό node.
  • Clinical Context (κέντρο): readiness, channels, roots/CN, πρωτόκολλα, gaps και επόμενες αποφάσεις για το επιλεγμένο node.
  • Εργαλεία (δεξιά): οργανωμένα σε καρτέλες ώστε να μη χρειάζεται ατελείωτο scroll.

Καρτέλες εργαλείων (δεξιά στήλη)

Η δεξιά στήλη έχει πέντε καρτέλες. Πάτησε την καρτέλα για να εμφανιστεί η αντίστοιχη ομάδα εργαλείων:

  • Χάρτης: ο διαδραστικός χάρτης σώματος με τα ηλεκτρόδια (και ο κοινός χώρος για Tele). Προεπιλεγμένη καρτέλα.
  • Σύνοδος: δημιουργία case, timeline events και AI Debrief.
  • Σήματα: import EDF/EDF+ και Alert Response Protocol.
  • AI: Clinical Copilot και DeepSeek Assistant.
  • Tele: ζωντανή απομακρυσμένη επίβλεψη. Ένα badge στην καρτέλα ειδοποιεί για εισερχόμενο αίτημα ακόμη κι αν είσαι σε άλλη καρτέλα.

Τυπική ροή

  1. Άνοιξε Live και διάλεξε node στο decision tree.
  2. Έλεγξε readiness, channels, roots/CN, protocols και body-map coverage.
  3. Στην καρτέλα Σύνοδος δημιούργησε case όταν χρειάζεται καταγραφή.
  4. Κατέγραψε timeline events με καθαρή, μη αναγνωριστική περιγραφή.
  5. Σε αλλαγή σήματος, χρησιμοποίησε την καρτέλα Σήματα για δομημένη αξιολόγηση.
  6. Χρησιμοποίησε AI ή Tele για υποστήριξη απόφασης.

Clinical workbench: SSEP & ειδικά πλάνα

Για SSEP nodes, το Clinical Context ομαδοποιεί αυτόματα τα κανάλια καταγραφής ανά γεννήτρια δυναμικού: περιφερικά (π.χ. N9/EP, N8, popliteal fossa), υποφλοιώδη (π.χ. N13, P14, N18, N22, P31) και φλοιώδη (π.χ. N20, P22, P37, N45). Η ομαδοποίηση δείχνει αμέσως αν λείπει φλοιώδες ή υποφλοιώδες κανάλι και βοηθά στον εντοπισμό του επιπέδου βλάβης (περιφέρεια έναντι νωτιαίου μυελού έναντι φλοιού). Όλα προκύπτουν ντετερμινιστικά από το καταχωρημένο SSEP montage του node.

Για χειρουργική θυρεοειδούς υπάρχει ειδικό procedure template (CIONM): παρακολούθηση του παλίνδρομου λαρυγγικού νεύρου (RLN) μέσω Vocalis με NIM ETT tube, του έξω κλάδου του άνω λαρυγγικού (EBSLN) μέσω κρικοθυρεοειδούς, και συνεχής διέγερση πνευμονογαστρικού (vagal CIONM) με APS ηλεκτρόδιο. Καταγράφεται η αλληλουχία V1/R1 → V2/R2 και ο κανόνας LOS (loss of signal) για σταδιακή θυρεοειδεκτομή. Το πλήρες πρωτόκολλο φαίνεται στα Protocols του node.

Χάρτης

Χάρτης σώματος

Ο χάρτης σώματος δείχνει τις θέσεις των ηλεκτροδίων (pins) πάνω σε ανατομικό μοντέλο, βαθμονομημένες σε ποσοστό με laterality L/R/C. Είναι η προεπιλεγμένη καρτέλα της δεξιάς στήλης.

  • Focus views: Full, Anterior, Posterior, Cranial, Upper limb, Posterior upper, Lumbosacral, Lower limb — εστιάζουν τον χάρτη στην περιοχή ενδιαφέροντος.
  • Pins: κάθε pin αντιστοιχεί σε μυ/ηλεκτρόδιο του επιλεγμένου node. Ο μετρητής δείχνει πόσα pins φαίνονται στο τρέχον view.
  • Κοινός χώρος Tele: κατά τη διάρκεια Tele συνεδρίας, εδώ εμφανίζονται τα shared annotations και ο συγχρονισμός view με τον συνεργάτη.
  1. Διάλεξε node στο decision tree για να φορτωθούν τα pins.
  2. Άνοιξε την καρτέλα Χάρτης.
  3. Διάλεξε focus view για την περιοχή που σε ενδιαφέρει.
Σήματα

Σήματα: Import & Alert Response Protocol

Η καρτέλα Σήματα έχει δύο εργαλεία: vendor-neutral import πραγματικών recordings και το Alert Response Protocol για δομημένη αξιολόγηση αλλαγών σήματος με δημοσιευμένα κριτήρια.

1. Vendor-neutral import (EDF/EDF+)

Φόρτωσε export .edf, .bdf ή .rec από οποιοδήποτε σύστημα (Cadwell, Natus, IONOMED κ.ά.). Το σύστημα εξάγει τα κανάλια και πραγματικές μετρήσεις peak-to-peak — δεν υπάρχουν εικονικά δεδομένα.

  1. Άνοιξε την καρτέλα Σήματα.
  2. Διάλεξε αρχείο EDF/EDF+ και πάτησε Import recording.
  3. Δες τη λίστα καναλιών με τις μετρήσεις τους.
  4. Πάτησε ένα κανάλι για να περαστεί αυτόματα στα πεδία του Alert Response Protocol.

2. Alert Response Protocol

Συγκρίνει baseline → current και βγάζει ντετερμινιστικό αποτέλεσμα (none / watch / warning / critical) με δομημένο διαφορικό πρωτόκολλο. Όλα τα όρια είναι αγκυρωμένα σε δημοσιευμένα κριτήρια IONM — κανένα δεν είναι αυθαίρετο.

  1. Διάλεξε Modality (SSEP άνω/κάτω, TcMEP, D-wave, BAEP, Triggered EMG, Free-running/cranial EMG).
  2. Συμπλήρωσε Channel και τιμές: baseline/current amplitude (µV), latency (ms), threshold (mA).
  3. Όρισε τη signature: laterality, onset, scope, και αν έγινε μετά από χειρισμό.
  4. Πάτησε Evaluate για το αποτέλεσμα και το πρωτόκολλο απόκρισης.
  5. Πάτησε AI proposals για προτάσεις με evidence retrieval.
  6. Πάτησε Log to timeline για να καταγραφεί στο ενεργό case.

Δημοσιευμένα κριτήρια συναγερμού

  • SSEP: πτώση amplitude ≥50% ή/και αύξηση latency ≥10% (ASNM/ACNS).
  • TcMEP (muscle): πτώση CMAP amplitude ≥80%, αύξηση threshold >100 V, ή all-or-none εξαφάνιση (critical).
  • D-wave: πτώση amplitude ≥50% προβλέπει μόνιμο κινητικό έλλειμμα.
  • BAEP: παράταση latency κύματος V ≥0.5–1.0 ms ή/και πτώση amplitude ≥50%.
  • Triggered EMG (pedicle): threshold <10–12 mA ύποπτο, <5–8 mA υψηλή ανησυχία για παραβίαση τοιχώματος.
  • Free-running EMG: παρατεταμένες neurotonic (train) εκφορτίσεις = μηχανικός/θερμικός ερεθισμός νεύρου.

Η ζώνη watch είναι συμβουλευτική τάση (60% του ορίου warning) και ξεχωρίζει πάντα από τα δημοσιευμένα όρια warning/critical.

Tele-IONM

Tele-IONM: ζωντανή απομακρυσμένη επίβλεψη

Το Tele-IONM επιτρέπει σε δύο συνδεδεμένους χρήστες να συνεργαστούν σε πραγματικό χρόνο: παρουσία ειδικών, αίτημα υποστήριξης, κοινός συγχρονισμένος χώρος (node + body map), shared annotations, chat, συγκατάθεση και πλήρες audit. Βρίσκεται στην καρτέλα Tele της δεξιάς στήλης.

Ποιος μπορεί να είναι ειδικός

Ειδικός μπορεί να γίνει χρήστης με access level Clinician, Educator ή Admin που ενεργοποιεί τον διακόπτη «Διαθέσιμος ως ειδικός». Οι Learners δεν εμφανίζονται ως ειδικοί.

Απαραίτητη προϋπόθεση

Χρειάζονται δύο συνδεδεμένοι χρήστες. Αν είσαι μόνος σου online, η λίστα ειδικών είναι κενή και το αίτημα είναι ανενεργό — αυτό είναι φυσιολογικό.

Ροή συνεδρίας

  1. Ειδικός: ενεργοποίησε «Διαθέσιμος ως ειδικός» στην καρτέλα Tele.
  2. Αιτών: διάλεξε ειδικό από τη λίστα, γράψε προαιρετικό μήνυμα και πάτησε Request remote support.
  3. Ειδικός: το badge στην καρτέλα Tele ανάβει· πάτησε Accept.
  4. Ανοίγει κοινή συνεδρία: chat, κοινός συγχρονισμένος node και body map.
  5. Δώσε συγκατάθεση κοινής προβολής για να ενεργοποιηθεί ο πλήρης κοινός χώρος.
  6. Στην καρτέλα Χάρτης κάνε κλικ για κοινά annotations· χρησιμοποίησε το pointer για δείκτη.
  7. Πάτησε End session για τερματισμό και προαιρετικά Attach to active case για σύνδεση με το ενεργό case (το timeline ενημερώνεται).

Όλη η συνεδρία (αιτήματα, αποδοχές, μηνύματα, annotations, τερματισμός) καταγράφεται για audit.

Αρχείο

Canonical channel map & σφραγισμένο αρχείο

Δύο εργαλεία μετατρέπουν τα recordings σε διασυστημικά, ντετερμινιστικά και αμετάβλητα κλινικά αρχεία: ο κανονικός χάρτης καναλιών (vendor-neutral ontology) και το σφραγισμένο αρχείο (tamper-evident hash chain). Ο κανόνας που διέπει τα πάντα: το AI προτείνει, ο άνθρωπος επιβεβαιώνει.

1. Canonical channel map (στην καρτέλα Σήματα)

Μόλις κάνεις import ένα recording, κάτω από τη λίστα καναλιών εμφανίζεται η κάρτα Canonical channel map. Κάθε ακατέργαστη ετικέτα κατασκευαστή (π.χ. Lt Tibial P37, L-Tib, LTIB) αντιστοιχίζεται σε έναν κανονικό κωδικό ανεξάρτητο κατασκευαστή (π.χ. ssep:tibial:L).

  • AI proposes (συμβουλευτικό): το σύστημα προτείνει αντιστοίχιση με ετικέτα heuristic και confidence μικρότερο του 1.0. Η πρόταση δεν μπαίνει ποτέ μόνη της στο επίσημο αρχείο.
  • Human confirms (ντετερμινιστικό): διάλεξε modality, anatomy και laterality και πάτησε Confirm. Η επιβεβαίωση γράφει μια learned αντιστοίχιση με confidence 1.0 και πλήρες audit.
  • Από εκεί και πέρα η ίδια (και κάθε κοσμητική παραλλαγή με παύλα/κενό/πεζά-κεφαλαία) επιλύεται ντετερμινιστικά ως learned. Κάθε ανθρώπινη διόρθωση κάνει το σύστημα εξυπνότερο.
  • Ο Admin μπορεί επιπλέον να επιλέξει promote σε global ώστε η αντιστοίχιση να ισχύει για όλη την πλατφόρμα· μόνο ο Admin έχει αυτό το δικαίωμα.

2. Σφραγισμένο αρχείο (καρτέλα Αρχείο)

Η καρτέλα Αρχείο στη δεξιά στήλη σφραγίζει το ενεργό case σε ένα αμετάβλητο, κρυπτογραφικά αλυσιδωτό αρχείο. Κάθε σφραγίδα περιέχει το πλήρες περιεχόμενο (case, timeline, canonical channel map) και ένα hash που κλειδώνει πάνω στην προηγούμενη σφραγίδα.

  1. Άνοιξε την καρτέλα Αρχείο με ενεργό case.
  2. Πάτησε Σφράγισε & κλείδωσε για να δημιουργηθεί η έκδοση 1 (v1) με μοναδικό hash.
  3. Νέα σφράγιση χωρίς αλλαγή περιεχομένου δεν δημιουργεί νέα έκδοση (idempotent) — το σύστημα αναγνωρίζει ότι το περιεχόμενο είναι ταυτόσημο.
  4. Μόλις αλλάξει κάτι (νέο timeline event, αλλαγή στον χάρτη καναλιών), η επόμενη σφράγιση δημιουργεί v2 που κλειδώνει στο hash του v1.
  5. Πάτησε Επαλήθευση ακεραιότητας για να ελεγχθεί ολόκληρη η αλυσίδα. Αν κάποια εγγραφή έχει αλλοιωθεί, η επαλήθευση το εντοπίζει (broken chain / altered).
  6. Η λίστα αρχείου δείχνει όλες τις σφραγισμένες εκδόσεις με την κατάσταση της αλυσίδας τους.

Έτσι το σύστημα γίνεται το αμετάβλητο, ελεγχόμενο «system of record» για IONM: ντετερμινιστικό, διασυστημικό και ανθεκτικό σε αλλοίωση. Το AI παραμένει πάντα συμβουλευτικό· μόνο ο άνθρωπος σφραγίζει το επίσημο αρχείο.

Cases

Cases, Report και Debrief

Τα Cases οργανώνουν περιστατικά ή σενάρια μέσα στην πλατφόρμα. Κάθε case μπορεί να έχει procedure context, timeline events, AI debrief και report.

  1. Άνοιξε Cases για λίστα και αναζήτηση.
  2. Άνοιξε case ή δημιούργησε νέο από Live.
  3. Κατέγραψε events στο timeline.
  4. Ζήτησε Debrief όταν υπάρχει αρκετή πληροφορία.
  5. Άνοιξε Report για ανασκόπηση και export μέσω print/PDF.

Το Debrief συνοψίζει τα γεγονότα, εντοπίζει κρίσιμα σημεία και δίνει recommendations με βάση το διαθέσιμο context. Το Report παρουσιάζει case summary, timeline και debrief σε καθαρή μορφή.

Academy

Εκπαιδευτικός χώρος μάθησης

Το Academy είναι εκπαιδευτικό workspace με Lesson, Placement, Waveforms, Tutor και Evidence. Το progress αποθηκεύεται όταν επιλεγεί learner.

  1. Επίλεξε learner από το Learner panel.
  2. Πάτησε Start Academy ή Continue.
  3. Διάβασε objectives, competencies, checklist και channel plan.
  4. Στο Placement τοποθέτησε targets στον body map όπου υπάρχει lab.
  5. Στο Waveforms άλλαξε amplitude drop, latency shift, threshold και noise για εκπαιδευτικά scenarios.
  6. Ολοκλήρωσε checkpoints, waveform quiz και case scenarios.
  7. Χρησιμοποίησε Tutor και Evidence για στοχευμένη επανάληψη.

Προσαρμοστική διαδρομή (adaptive path)

Όταν επιλεγεί learner, το Academy χτίζει αυτόματα μια προσαρμοστική διαδρομή με βάση το πραγματικό progress και τα λάθη του. Κάθε βήμα έχει προτεραιότητα: remediate (μάθημα με λάθη που χρειάζεται επανάληψη), continue (ξεκίνησε αλλά δεν ολοκληρώθηκε) και start (νέο μάθημα). Το κουμπί «Continue» πάει πάντα στο πιο επείγον βήμα της διαδρομής, ώστε η μάθηση να γίνεται case-driven και εξατομικευμένη αντί για στατική σειρά.

Waveform Lab: σύγκριση με baseline

Στο Waveform Lab κάθε scenario (εκτός του baseline) προβάλλει τη baseline κυματομορφή ως διακεκομμένη γραμμή αναφοράς πίσω από την τρέχουσα, με βαθμονόμηση πλάτους σε µV και χρόνου. Κάτω από κάθε κανάλι εμφανίζεται η διαφορά από το baseline: ποσοστό πτώσης πλάτους και μετατόπιση latency, χρωματισμένα ok/warning/alarm σύμφωνα με τα δημοσιευμένα όρια. Έτσι ο εκπαιδευόμενος μαθαίνει να ερμηνεύει αλλαγές όπως στην πραγματική κλινική πράξη. Όλες οι κυματομορφές είναι εκπαιδευτική προσομοίωση, όχι καταγραφές ασθενούς.

AI

AI εργαλεία και evidence

Τα AI εργαλεία απαντούν με βάση το επιλεγμένο context: node, lesson, Knowledge Base, protocols, bibliography, case timeline και προηγούμενα mistakes. Χρησιμοποιούνται για υποστήριξη χειρισμού, reasoning και review — πάντα με ανθρώπινο έλεγχο.

Clinical Copilot (καρτέλα AI στο Live)

Δίνει δομημένο κλινικό brief για το επιλεγμένο node. Έχει τρεις εστιάσεις:

  • Setup: προετοιμασία, montage, baselines και readiness.
  • Signal: ερμηνεία αλλαγής σήματος και επόμενα βήματα.
  • Evidence: τεκμηρίωση από Knowledge Base και βιβλιογραφία.

Πρόσθεσε προαιρετικά παρατήρηση/φάση (χωρίς προσωπικά δεδομένα) και πάτησε Run Clinical Copilot.

DeepSeek Assistant

Ελεύθερη ερώτηση με βάση το επιλεγμένο node. Κατάλληλο για στοχευμένες, σύντομες ερωτήσεις.

Άλλα AI

  • AI Tutor: ερωτήσεις πάνω στο επιλεγμένο Academy lesson.
  • Case Debrief: ανασκόπηση timeline και recommendations (καρτέλα Σύνοδος / σελίδα Cases).
  • Evidence retrieval: ανακτά σχετικά αποσπάσματα όπου υπάρχουν.

Καλή χρήση σημαίνει συγκεκριμένη ερώτηση, σωστό επιλεγμένο context και ανθρώπινος έλεγχος της απάντησης.

Τεκμηρίωση & grounding (citations)

Η ανάκτηση evidence γίνεται σε δύο στάδια: semantic embeddings και στη συνέχεια neural rerank (Jina reranker) που ανεβάζει τα πιο σχετικά αποσπάσματα — με αυτόματη υποχώρηση σε καθαρή ομοιότητα αν το rerank δεν είναι διαθέσιμο. Κάθε citation που επιστρέφει το AI ελέγχεται ντετερμινιστικά (grounding) απέναντι στα πραγματικά ανακτημένα έγγραφα: όσες πηγές επαληθεύονται σημειώνονται ως grounded με την προέλευσή τους (collection/key), ενώ όσες δεν αντιστοιχούν σε ανακτημένο υλικό επισημαίνονται ως μη τεκμηριωμένες. Έτσι ξεχωρίζεις άμεσα ποιες προτάσεις στηρίζονται σε πραγματική βιβλιογραφία.

Checklist

Λειτουργικός έλεγχος παράδοσης

  1. Admin login επιτυχημένο.
  2. Normal user login επιτυχημένο.
  3. Normal user δεν ανοίγει Admin.
  4. Admin δημιουργεί user με username, password, first name, last name, email και phone.
  5. Admin κάνει reset password.
  6. Knowledge Base upload εμφανίζει το PDF στα documents.
  7. Live ανοίγει node και εμφανίζει channel/body-map context.
  8. Case δέχεται timeline events.
  9. Debrief παράγεται και αποθηκεύεται.
  10. Report ανοίγει για το case.
  11. Academy lesson αποθηκεύει learner progress.
  12. AI Tutor απαντά στο επιλεγμένο lesson context.
  13. Η δεξιά στήλη του Live εναλλάσσει καρτέλες (Χάρτης, Σύνοδος, Σήματα, AI, Tele).
  14. EDF/EDF+ import εμφανίζει κανάλια με πραγματικές μετρήσεις.
  15. Alert Response Protocol βγάζει αποτέλεσμα και γράφεται στο timeline.
  16. Tele-IONM: αίτημα, αποδοχή, κοινός χώρος, chat και σύνδεση με case.
