Somatosensory Evoked Potentials

Παρακολούθηση αισθητικών οδών (οπίσθιες δεσμίδες). Συμπληρώνει το EMG/MEP σε επεμβάσεις σπονδυλικής, αορτής, καρωτίδας.

Κριτήρια ειδοποίησης

Warning criteria
Cortical SSEP changes
  • 50% πτώση πλάτους από baseline
  • 10% αύξηση λανθάνουσας από baseline
  • Πλήρης απώλεια κύματος → άμεση ειδοποίηση χειρουργού

Έλεγχος πρώτα τεχνικά (ηλεκτρόδια, πίεση, θερμοκρασία, αναισθησία) πριν κρίνεις χειρουργικό συμβάν.

Anesthesia notes
Optimal protocol

Volatile: ≤ 0.5 MAC (ιδανικά TIVA)

N₂O: αποφυγή — μειώνει cortical SSEP

Propofol/remi TCI: συνιστώμενο

NMB: ΟΚ για SSEP (όχι για EMG/MEP)

Pedicle Screw Stimulation (t-EMG)

Ηλεκτρική διέγερση της βίδας ή του pilot hole· καταγραφή από τους μυς της αντίστοιχης ρίζας. Χαμηλό κατώφλι ⇒ πιθανή ρήξη φλοιού.

Κατώφλι (mA)ΕρμηνείαΕνέργεια
> 10 mAΆθικτος αυχένας — ασφαλής τοποθέτησηΣυνεχίζει η επέμβαση
5–10 mAΑμφίβολο — πιθανή λέπτυνση φλοιούΕπανεκτίμηση screw track, ψηλάφηση
< 5 mAΠιθανή ρήξη φλοιούΑφαίρεση / επανατοποθέτηση
Τεχνική
Stimulation protocol

Έλεγχος NMB: TOF 4/4 πριν τη μέτρηση. Ζήτα reversal αν χρειάζεται.

Stimulator: μονοπολικό probe στο screw shaft ή pilot hole.

Παράμετροι: τετραπλή σειρά παλμών, 0.2–0.3 ms duration, αύξηση από 0 mA.

Επανάληψη: 2–3 φορές. Καταγραφή από αμφότερα μυικά κανάλια ρίζας.

Pitfalls
Συχνές παγίδες
  • NMB: false high thresholds
  • Διαρροή ρεύματος: αίμα/ορός γύρω από βίδα → false low
  • Οστεοπόρωση: χαμηλότερα thresholds
  • Cement / fusion mass: παρεμβολή

Mυς ανά ρίζα (γρήγορη αναφορά)

Κρανιακά νεύρα (μεμονωμένα)

Επίλεξε κρανιακά νεύρα ή πρότυπο

Παρακολούθηση Παλίνδρομου Λαρυγγικού (RLN)

Κλάδος του πνευμονογαστρικού (CN X). Standard: NIM endotracheal tube με ηλεκτρόδια στις φωνητικές χορδές.

RLN — Recurrent Laryngeal
CN X branch · Vocalis
Setup
NIM ETT — surface electrodes ανάμεσα στις χορδές
Tube size
7.0 (♀) / 8.0 (♂)
Stim
1.0 mA, response 100–800 μV
Latency
3.5 – 7.5 ms
Πρωτόκολλο
V1 → R1 → R2 → V2

LOS: πτώση πλάτους >50% και/ή λανθάνουσα >10%.

eSLN — External Superior Laryngeal
CN X branch · Cricothyroid
Setup
Επιφανειακά/βελονοειδή στον κρικοθυρεοειδή
Stim
1.0 mA + ορατό twitch
Σημασία
Τόνος φωνής, υψηλές συχνότητες
Risk
Άνω πόλος → Berry's ligament

Κρίσιμο σε τραγουδιστές, εκπαιδευτικούς, επαγγελματίες ομιλίας.

Vagus baseline (V1/V2)
Reference standards

V1: stim στο vagus πριν την παρασκευή — επιβεβαιώνει σύστημα.

V2: stim στο vagus μετά αφαίρεση — επιβεβαιώνει ακέραιο RLN.

Anesthesia notes
For thyroid IONM

NMB: ΧΩΡΙΣ μυοχάλαση μετά διασωλήνωση (ή sugammadex).

ETT: μπλε γραμμή ορατή στις φωνητικές χορδές.

Position: ETT shift κατά παρασκευή = false LOS.

Export coordinates

Αυτό είναι το JSON με τις τρέχουσες συντεταγμένες (defaults + οι αλλαγές σου). Αντικατάστησε τη μεταβλητή MUSCLE_COORDS στον κώδικα HTML για να τις κάνεις permanent. Οι αλλαγές σου ήδη αποθηκεύτηκαν στον browser σου.

Import coordinates

Επικόλλησε JSON object με συντεταγμένες μυών. Δέχεται είτε καθαρό JSON είτε το format const MUSCLE_COORDS = {...};. Θα αντικαταστήσει τις τρέχουσες θέσεις των μυών που υπάρχουν στο JSON — οι υπόλοιποι μένουν ίδιοι.
